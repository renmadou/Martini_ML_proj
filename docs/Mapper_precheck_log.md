# Mapper 官能团支持预检日志（第 2 周·周二，2026-11-12）

> 目的：周三正式运行前，逐分子判断 Martini Mapper 能力边界，失败定位到具体碎片/官能团。
> 运行方式：`conda run -n martini_mapper python -m martini_mapper <Name> <SMILES> --no-xtb`（产物在 `benchmarks/mapper_outputs/precheck/`，gitignore）。
> 诊断脚本：`/tmp/folate_diag.py`（逐 section 隔离测试）。

## 结果总览

| 分子 | 状态 | 失败定位 | 边界判断 |
|---|---|---|---|
| BPDC（阴性对照） | ✅ 直接成功 | — | 覆盖范围内 |
| α-CD | ⚠️ 直接成功但映射方案存疑（见下） | — | 覆盖范围内，但与 Martini 3 碳水化合物原生构建块不一致 |
| 叶酸 | ❌ 完全失败（无任何输出文件） | 两处独立硬伤：① 蝶呤环的嘧啶酮环；② 谷氨酸尾整段 | 均为"字典/算法未覆盖"，非"珠子层面不可表达" |
| Folate–M²⁺ 片段 | 本周不运行（按计划） | — | — |

## 1. BPDC — 阴性对照通过

- 8 beads：2 个苯环 = 6×TC5（每环 3 个二原子珠子），2 个羧基各为独立 **SP2**（C,O,O 三原子，mass 54，1 连接）。
- 键长/键连接正常（`--no-xtb` 下 bonds 已给出，与苯基线行为一致）。
- 结论：环境与参数调用正常；羧基**被赋予标准珠子**且两个羧基**各自独立成珠，未合并**——这对叶酸"两个羧基合并为单一负电珠子"的假说是一个重要的负面先验：Mapper 的字典里没有"双羧基合一"的路径（至少在 BPDC 这种间距下没有）。
- 备注：阎云老师 2026-11-12 确认实验投料为 BPDC **钠盐**（`molecule_set_SMILES.csv` 已更新）；正式运行与第 4/6 周需补 BPDC²⁻ 对比行。

## 2. α-CD — 成功但需人工复核

- 24 beads / 126 原子：6×TP1(CH₂OH) + 6×TN4a + 7×SP4 + 4×SN6 + 1×TC3（详见 `alpha-CD.txt`）。
- 观察点记录：
  1. **环状闭合拓扑被保留**：闭合键出现在 Bead connections 中（bead 2–17、16–17 等），未被当作开链寡糖。
  2. **每葡萄糖 4 beads**（Martini 3 原生碳水化合物构建块为每葡萄糖 3 beads）——Mapper 过度细分，与 Martini 3 系统性碳水化合物参数化**不一致**。
  3. **糖苷氧归属**：每个 TN4a(C,O) 珠子各含一个 O——即环内 O/糖苷 O 与碳配对成珠，而非 Martini 3 碳水化合物的标准归属方式；这正是第 5 周分歧表的预定条目。
  4. 出现 1 个 **TC3(C,C)** 珠子（4 连接）——TC 型珠子用于碳水化合物骨架在化学上可疑，需周三正式运行时用 RDKit 原子编号核对其位置（疑似环闭合处的 C1–C4 连接碳）。
  5. `--no-xtb` 模式下键长为默认值，仅供拓扑预检。

## 3. 叶酸 — 完全失败，两处独立硬伤

Mapper 输出 7 个 section：0=PABA 苯环（type 2）、1=蝶呤吡嗪环（type 2）、**2=蝶呤嘧啶酮环（type 2）**、3=谷氨酸尾+苯甲酰胺（type 0，12 原子）、4–6=小碎片。报错 `mapping section 2 failed: Benzene ring section not fully mappable!`，重试后仍失败，无输出文件。

逐 section 隔离测试 + 碎片分子测试定位：

### 硬伤 ①：蝶呤环的嘧啶酮环（鸟嘌呤样内酰胺）

- section 2 = 原子 {23,24,26,28,29,30}（C,C,C,N,C,N），含 1 个环外 C=O（gid 27）、1 个环外 NH₂（gid 31）、与吡嗪环共用 2 个稠合原子（23,24）。
- 失败机制：稠合原子 24,26 被并入 SN6a 珠子、29 并入 TN6d 后，剩余 {23(C), 28(N)} 两个芳香环原子在 benzene-ring 流程的 Step 8 找不到可配对的珠子——**稠合双环的第二个环在该流程中无可用配对方案**。
- 碎片验证：
  - 蝶啶（无取代稠合双环 `C1=CN=C2C(=N1)C=NC(=N2)`）✅ 成功；
  - 蝶呤（`C1=CN=C2C(=N1)C(=O)NC(=N2)N`，即蝶啶 + 内酰胺 C=O + NH₂）❌ 同样报 "Benzene ring section not fully mappable!"；
  - PABA（对氨基苯甲酸）✅ 成功 → PABA 半侧无问题。
- 结论：**触发失败的是蝶呤环上的内酰胺 C=O / NH₂ 取代模式**（鸟嘌呤样 C(=O)–N–C(=N) 片段在芳香稠环上无匹配珠子），而非稠环本身。
- 边界判断：**字典未覆盖**（化学上 Martini 3 有鸟嘌呤标准珠子，信息在珠子层面可表达，是此工具的碎片规则没写这种情形）。

### 硬伤 ②：谷氨酸尾整段（独立于蝶呤问题）

- L-谷氨酸单体 `N[C@@H](CCC(=O)O)C(=O)O` ❌ 报 "Non‐ring section division leads to unassignable sections"——**α-碳同时带 –NH₂ 与 –COOH、且三键外还有第二个 –COOH** 的支化非环碎片无法被单珠子/细分流程分配。
- 对照（全部 ✅）：甘氨酸 `NCC(=O)O`、丙氨酸 `NC(C)C(=O)O`、琥珀酸 `OC(=O)CCC(=O)O`、GABA `NCCCC(=O)O`、乙酸。
- 结论：**单个羧基、单个氨基酸均可映射；失败特异地由"α-氨基酸 + 远端第二羧基"组合触发**。
- 对第 2 周核心假说的影响：**"谷氨酸尾两个羧基是否合并为单一负电珠子"在当前版本工具下不可测试**——谷氨酸尾在环映射之前就已失败（且 BPDC 结果显示 Mapper 倾向每羧基一个 SP2，合并路径不存在）。周三正式运行时叶酸预计仍整体失败，此假说需改由 MolCluster 侧或手工映射验证。
- 边界判断：**字典未覆盖**（谷氨酸是 Martini 3 标准氨基酸，可表达；工具非环细分算法不支持）。

## 4. 初步结论与周三预案

1. BPDC、α-CD 可进入周三正式运行（α-CD 需带上述 4 个观察点人工复核）。
2. 叶酸两条路线均预期失败，属工具能力边界（字典/算法未覆盖），**不是**珠子层面不可表达。周三选项：
   - (a) 跑碎片（PABA、蝶呤、谷氨酸）分别与 MolCluster 对比，拼合评估；
   - (b) 手工给蝶呤环写映射（参考 Martini 3 鸟嘌呤珠子）后对比；
   - (c) 直接记为 Mapper 不支持条目，转入 MolCluster-only。
3. 谷氨酸"双羧基合并"假说在 Mapper 侧已提前证伪（羧基各自独立成珠），证据来自 BPDC + Glu 失败 + 碎片对照。
