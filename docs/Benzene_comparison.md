# outputs/Benzene_default 与 outputs/Benzene_noxtb 对比

两个目录结构相同，均包含 `Benzene.gro`、`Benzene.itp`、`Benzene.txt` 三个文件。

其中 `Benzene.gro` 和 `Benzene.txt` 完全一致，差异只在 `Benzene.itp` 的成键参数部分。

## Benzene_default（走 xtb 流程）

- 使用 `[ constraints ]` 固定三条 bead 间距离，键长来自 xtb 优化后的实际几何：0.28773 / 0.28786 / 0.28765 nm，不带力常数
- 额外包含 `[ angles ]` 段：三个角约 60°，力常数由 xtb 计算（15026.42 / 19985.45 / 19097.89 kJ/mol/rad²）
- 包含 `[ dihedrals ]` 段头

```ini
[ constraints ]
;  ai    aj   funct      b0(nm)
    1     2     1      0.28773
    1     3     1      0.28786
    2     3     1      0.28765

[ angles ]
;  ai    aj    ak  funct     th0(deg)        k(kJ/mol/rad^2)
    1     2     3     1     60.04196         15026.42
    1     3     2     1     59.99339         19985.45
    2     1     3     1     59.96465         19097.89
```

## Benzene_noxtb（不走 xtb）

- 键用普通 `[ bonds ]` 表示，三条键统一使用默认键长 0.29103 nm、固定力常数 k = 20000 kJ/mol/nm²
- 没有 angles、dihedrals 参数（无几何优化数据可用）

```ini
[ bonds ]
;  ai    aj   funct      b0(nm)        k
    1     2     1      0.29103    20000
    1     3     1      0.29103    20000
    2     3     1      0.29103    20000
```

## 结论

- default 的键长/角/力常数是 xtb 按分子实际几何计算得到的"定制"参数，更精确
- noxtb 退回统一的默认经验参数，只能保证拓扑正确，平衡几何是近似的
- 另外 atomtypes 表头存在一处空格对齐的微小格式差异（`type  resnr` vs `type resnr`）

## 初步结论：复杂分子应采用哪种模式

对于复杂分子（多环、含支链、刚柔混合结构等），**初步建议优先采用 default（xtb）模式**，理由如下：

1. **几何真实性**：复杂分子中 bead 间距离和夹角随局部化学环境差异较大，统一默认值（0.29103 nm / k=20000）难以同时拟合所有键，noxtb 模式会引入明显的平衡几何误差；xtb 模式按优化后的实际几何给出每条键/角的参数。
2. **约束 vs 谐振键**：xtb 模式用 constraints 刚性固定键长，配合由 Hessian 导出的角度力常数，更不容易出现复杂拓扑下的软模失真；noxtb 的固定 k=20000 谐振键在刚柔混合体系中可能造成不合理的能量分配。
3. **角度参数不可缺省**：复杂分子的构象主要由键角和二面角决定，noxtb 完全缺失 angles/dihedrals 参数，复杂体系下构象行为基本不可信；而苯是高度对称的平面环，恰好掩盖了这一缺陷。

**noxtb 的适用场景**：仅作为快速预检（验证映射拓扑是否正确）、或 xtb 不可用时的降级方案；其输出不宜直接用于生产性 MD 模拟。

> 注意：以上结论目前仅基于苯这一个高对称小分子得出，属于初步判断。建议在若干复杂分子（如阿司匹林、多环芳烃、柔性长链分子）上重复本对比后再最终定论。
